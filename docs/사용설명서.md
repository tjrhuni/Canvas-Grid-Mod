# YUBYEOL's Canvas Grid Mod 사용 설명서

아트맵 이젤에서 그림을 그릴 때 도화지 위에 32×32 모눈을 띄우고, 지금 시선으로 클릭하면 어느 칸이
칠해지는지 보여 주는 클라이언트 모드입니다. 화면에 그리기만 하며 자동 클릭·자동 조준·서버 통신은
전혀 없습니다.

## 설치

1. Fabric 1.21.4에 Fabric API가 설치된 상태에서 `yubyeol-canvas-grid-<버전>.jar`를 `mods` 폴더에
   넣습니다.
2. Mod Menu가 있으면 모드 목록에서 설정 버튼이 생깁니다. 없어도 조작 설정에서 "캔버스 그리드 설정
   열기" 키를 지정해 열 수 있습니다.

## 화면에 보이는 것

| 표시 | 언제 | 설명 |
| --- | --- | --- |
| 모눈 | 이젤에 앉았을 때 (설정으로 항상 표시 가능) | 32×32 칸. 4칸마다 굵은 선, 위·왼쪽에 4, 8, 12 … 눈금 숫자 |
| 포인터 테두리 | 이젤에 앉았을 때 | 지금 클릭하면 칠해질 칸. 십자선과 다를 수 있으며, 테두리가 맞는 쪽입니다 |
| 픽셀 좌표 | 이젤에 앉았을 때 | 화면 구석에 "픽셀 16, 14". 왼쪽 위가 1, 1 |

십자선과 테두리가 다른 이유: 아트맵은 십자선이 닿은 자리가 아니라 앉은 사람의 시선 각도를 표로
바꿔 칸을 정합니다. 이 모드는 같은 표를 써서 계산하므로 테두리가 실제로 칠해지는 칸입니다.

## 키

| 키 | 기본값 | 용도 |
| --- | --- | --- |
| 캔버스 그리드 켜기/끄기 | G | 오버레이 전체를 끄고 켭니다. 완성작을 볼 때 끄면 됩니다 |
| 캔버스 그리드 설정 열기 | 없음 | 설정 화면을 엽니다 |

## 설정 항목

설정 화면에서 항목 위에 마우스를 올리면 같은 설명이 뜹니다. 바꾸는 즉시 저장되고 적용됩니다.

### 표시 켜고 끄기

- **오버레이 표시** — 모눈, 포인터, 좌표를 한꺼번에 켜고 끕니다. 단축키와 같은 기능입니다.
- **앉았을 때만 표시** — 이젤에 앉아 있을 때만 모눈과 좌표를 그립니다. 일어서면 그림만 보여서
  전시된 그림이 모눈에 가려지지 않습니다. 끄면 근처 이젤 도화지에 항상 모눈이 보입니다.
- **눈금 숫자** — 도화지 위와 왼쪽의 4, 8, 12 … 숫자입니다. 도안 좌표를 보면서 찍을 때 칸을 세지
  않아도 되게 해 줍니다.
- **포인터 테두리** — 앉았을 때 칠해질 칸의 테두리입니다. 끌 일은 거의 없지만, 모눈만 보고 싶을 때
  끕니다.
- **픽셀 좌표 표시** / **좌표 표시 위치** — 화면 구석의 좌표 글자와 그 자리(네 모서리 중 하나)입니다.
  채팅창이나 미니맵과 겹치면 자리를 옮기세요.

### 모눈 모양

- **선 굵기 (1~5)** — 멀리서 작업하면 굵게, 세밀한 부분을 찍을 때는 얇게. 굵은 선은 이 값의 두 배로
  그려집니다.
- **선 불투명도 (0~100%)** — 얇은 선이 그림을 얼마나 가릴지. 낮추면 그림이 잘 보이고 높이면 칸을
  세기 쉽습니다. 굵은 선과 테두리는 자동으로 더 진합니다.
- **그리드 색상** — 그림의 주된 색과 반대되는 색을 고르면 잘 보입니다. 밝은 그림엔 검정, 어두운
  그림엔 흰색이나 노랑을 권합니다.
- **굵은 선** / **굵은 선 간격 (2·4·8·16칸)** — 일정 간격마다 선을 굵게 그려 "세 번째 묶음의 두 번째
  칸"처럼 위치를 빨리 찾게 합니다. 눈금 숫자도 같은 간격을 따릅니다. 도안을 나눈 단위에 맞추세요.

### 픽셀과 포인터

- **픽셀 선명하게** — 도화지를 가까이서 보면 지도 텍스처가 흐려져 픽셀이 칸 밖으로 번져 보입니다.
  켜면 이미 받아 둔 지도 데이터로 픽셀을 또렷한 정사각형으로 다시 그려 찍은 픽셀이 칸에 정확히
  들어갑니다. 색은 원래 지도와 같습니다. 원래 지도 질감을 보고 싶을 때만 끕니다.
- **포인터 색상** — 테두리 색입니다. 지금 칠하는 색과 겹치지 않게 두면 놓치지 않습니다.
- **포인터 굵기 (1~5)** — 테두리 두께입니다. 칸 안의 색을 보면서 찍고 싶으면 얇게, 멀리서도 눈에
  띄게 하려면 굵게 둡니다.

### 기타

- **이젤 탐색 범위 (2~16블록)** — 이 거리 안의 이젤 도화지에만 모눈을 그립니다. 이젤이 여러 개면
  바라보는 것과 가까운 것을 우선합니다. 전시 액자까지 잡히면 줄이고, 모눈이 안 뜨면 늘리세요.
- **기본값으로 되돌리기** — 처음 설치했을 때의 값으로 돌립니다.

## 권장 사용법

1. 도안을 4칸 단위로 나눠 두고 굵은 선 간격을 4로 둡니다.
2. 이젤에 앉아 도안의 좌표를 보며 픽셀 좌표 글자가 같은 숫자를 가리킬 때 클릭합니다.
3. 찍은 픽셀이 칸에 정확히 들어가는지 "픽셀 선명하게"를 켠 채로 확인합니다.
4. 완성 후에는 G 키로 오버레이를 끄고 감상합니다.

## 문제가 생기면

- 모눈이 안 뜸: 이젤이 탐색 범위 안에 있는지, 오버레이가 켜져 있는지 확인합니다.
- 모눈이 도화지와 어긋남: 설정 파일의 `surfaceOffset`(블록 단위, -0.1~0.1)으로 평면을 미세 조정할 수
  있습니다.
- 다른 모드와 좌표 글자가 겹침: 좌표 표시 위치를 바꿉니다.
